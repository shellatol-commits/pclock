# Security Policy

## Allowed Ways

| Version | Supported          |
| ------- | ------------------ |
| Email from us   | :white_check_mark: |
| Issue or discussion   | :x: |
| Via Nexus Chat   | ... |
| Via Social   | :x: |


## If Someone Disrespects
Tell them. If they do not listen, ask us to lock the chat.
If it's via Nexus Chat, think. If it's only private remembrances or a private conversation, it's okay. If it's meant to be social, ask the chat owner.
If it's via social, ask the chat moderators or the owner (of the message or the chat).
